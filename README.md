# SolESS Lab

### PV Modelling • Performance Analytics • Energy Systems

**SolESS Lab** is a technical portfolio focused on photovoltaic system modelling, operational data analysis, and reproducible engineering workflows.

Current work follows the PV modelling chain:

**Solar Resource → Irradiance → Module Temperature → DC Power → Inverter Conversion → AC Output → Validation**

## Current Focus

- PV system modelling with **pvlib**
- irradiance and transposition modelling
- module temperature and electrical models
- DC and AC power modelling
- model validation against measured data
- PV data quality with **PVAnalytics**
- expected vs. measured performance
- PV power forecasting
- reproducible Python workflows

## Core Tools

**pvlib-python** · **PVAnalytics** · Python · Pandas · NumPy · SciPy · Matplotlib

Methods are selected using primary literature, PVPMC guidance, and relevant standards.

## Current Project

### `pv-modeling-and-analytics`

A structured PV modelling and validation workflow from environmental inputs to simulated power and comparison with measured system behaviour.

## Approach

- physically meaningful models
- transparent assumptions
- reproducible analysis
- explicit validation
- traceable references
- clear treatment of uncertainty and limitations
